# Design

## Почему id в протоколе, а файлы в дисплее

Тот же раскол, который уже сделан для эффектов и для визуальных ассетов: пресет валидирует сервер,
значит список допустимых id обязан быть общим; сами mp3 нужны только тому, кто их играет. Сервер,
собранный без единого байта звука, продолжает отвергать пресет, называющий несуществующий звук, а
дисплей ловит обратную ошибку — id есть, файла нет — своим тестом. Между этими двумя проверками щели
не остаётся.

## Почему Web Audio, а не звуковой менеджер Phaser

Музыка должна пережить пересоздание сцены, а пульт громкости живёт в React-оболочке, не в Phaser.
Менеджер Phaser привязан к жизненному циклу игры и к её контексту, поэтому оболочке пришлось бы
ходить внутрь сцены за громкостью, а темы — останавливаться на каждом входе в бой. Автобус на Web
Audio — это два `GainNode` и словарь декодированных буферов: сцена только называет звук и точку, всё
остальное считается снаружи.

Из этого следует и тестируемость. У дисплея нет DOM в тестах — компоненты рендерятся в строку, —
поэтому чистая часть (громкость, Mute, потолок копий, затухание) вынесена в модуль без единого
обращения к Web Audio и проверяется как арифметика. Драйвер остаётся тонким: загрузить,
декодировать, подключить, запустить.

## Почему громкость не в пресете

Пресет — это баланс игры, один на всех и общий для всех комнат. Громкость — свойство комнаты, в
которой стоит экран: на одном стенде колонки, на другом ноутбук на кухне. Настройка живёт в
`localStorage` того устройства, которое её сделало, и не ходит по сети вовсе — поэтому её изменение
не может ни сломать матч, ни потребовать прав администратора.

## Потолок копий и затухание

Шестнадцать кораблей на поле — это залпы, в которых один и тот же звук пушки может начаться десять
раз за кадр. Без потолка это складывается в клиппинг, а не в громкость. Поэтому у каждого id есть
предел одновременных копий и минимальный промежуток между запусками, а событие дальше кадра
ослабляется по расстоянию и за некоторым радиусом не запускается вовсе — та же логика, по которой
сцена не строит то, чего игрок не видит.
