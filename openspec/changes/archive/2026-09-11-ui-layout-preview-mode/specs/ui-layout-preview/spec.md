## ADDED Requirements

### Requirement: Dev-сборка открывает игровую верстку без сервера

Controller и display SHALL в dev-сборке по параметру `?preview=1` рендерить игровой экран из
фикстуры вместо экрана входа и SHALL NOT создавать сетевого клиента и комнату. Production-сборка
SHALL игнорировать параметр и вести себя как сейчас.

#### Scenario: Сервер не запущен

- **WHEN** dev-сборка controller открыта с `?preview=1` при остановленном игровом сервере
- **THEN** боевой экран роли отрисован полностью, поле ошибки пустое, попыток подключения нет

#### Scenario: Display без комнаты

- **WHEN** dev-сборка display открыта с `?preview=1`
- **THEN** HUD, радар и мир отрисованы из снапшота фикстуры без создания комнаты

#### Scenario: Production-сборка

- **WHEN** production-сборка открыта с `?preview=1`
- **THEN** показан обычный экран входа, а preview-панель отсутствует

### Requirement: Preview переключает роль и фазу без перезагрузки

Preview SHALL предоставлять переключение роли между `pilot`, `gunner`, `shield` и фазы между
`lobby`, `combat`, `intermission` и `result`. Смена значения SHALL немедленно перерисовывать экран
из соответствующей фикстуры.

#### Scenario: Смена роли

- **WHEN** в preview выбрана роль `shield` вместо `pilot`
- **THEN** отрисованы элементы управления щитом, а элементы пилота отсутствуют

#### Scenario: Смена фазы

- **WHEN** в preview выбрана фаза `intermission`
- **THEN** отрисована панель командного голосования с карточками улучшений

#### Scenario: Экран результата

- **WHEN** в preview выбрана фаза `result`
- **THEN** отрисована панель итога забега с готовностью к новому бою

### Requirement: Preview не отправляет игровые команды

Preview SHALL обрабатывать пользовательский ввод локально и SHALL NOT отправлять intents, голоса и
ready-команды. Отсутствие соединения SHALL NOT приводить к сообщению об ошибке.

#### Scenario: Управление стиком в preview

- **WHEN** игрок ведёт joystick и удерживает action-zone в preview
- **THEN** визуальная обратная связь работает, сетевых сообщений нет, поле ошибки пустое

#### Scenario: Голос за улучшение в preview

- **WHEN** в preview нажата карточка улучшения
- **THEN** карточка показывает выбор локально и команда голосования не отправляется

### Requirement: Фикстуры preview соответствуют протоколу

Каждая фикстура preview SHALL проходить `controllerRoomViewSchema.parse` либо
`displayRoomViewSchema.parse`, чтобы preview показывал только состояния, достижимые по протоколу.

#### Scenario: Проверка фикстур

- **WHEN** unit-тест парсит каждую фикстуру preview соответствующей схемой протокола
- **THEN** парсинг проходит без ошибок для всех комбинаций роли и фазы

#### Scenario: Фаза лобби

- **WHEN** выбрана фаза `lobby`
- **THEN** фикстура содержит `runNumber` равный нулю и `game` равный `null`, как требует протокол
