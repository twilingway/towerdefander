## Why

Главный экран не показывает состояние перегрева пилотского пулемёта и не даёт экипажу обзора всей
арены за пределами камеры. Из-за этого пилот теряет момент блокировки оружия, а команда поздно
замечает приближающиеся угрозы.

## What Changes

- Добавить в боевой HUD главного display authoritative шкалу нагрева пулемёта и явное состояние
  перегрева.
- Добавить круглую полупрозрачную мини-карту всей арены в стиле космического радара.
- Показывать на мини-карте общий корабль экипажа и вражеские корабли из текущего display snapshot.
- Разместить радар снизу по центру над основным combat HUD.
- Сохранить читаемость игрового поля и HUD на desktop, телевизоре и узких поддерживаемых экранах.
- Не менять simulation, protocol, server authority, баланс или механику оружия.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `primitive-top-down-battlefield`: боевой React HUD получает authoritative индикатор перегрева и
  круглый обзорный радар всей арены.

## Impact

- Затрагиваются `apps/display` и display-тесты.
- Новые production dependencies, protocol changes и deployment changes отсутствуют.
- Совместимость с текущими комнатами сохраняется: используются уже опубликованные поля protocol v12.
