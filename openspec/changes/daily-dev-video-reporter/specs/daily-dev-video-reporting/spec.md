## ADDED Requirements

### Requirement: Отчёт-исходник за дату опирается на Git

Локальная команда отчёта SHALL принимать дату в формате `YYYY-MM-DD`, выбирать только коммиты,
попадающие в этот локальный календарный день, и записывать Markdown-исходник в
`artifacts/daily-videos/<date>/research.md`. Для каждого коммита исходник SHALL содержать hash и
subject; отсутствие коммитов SHALL быть явно отражено и не считаться ошибкой.

#### Scenario: В дату есть коммиты

- **WHEN** пользователь запускает отчёт с датой, в которую есть коммиты
- **THEN** `research.md` содержит эту дату, количество коммитов, hash и subject каждого выбранного
  коммита

#### Scenario: В дату нет коммитов

- **WHEN** пользователь запускает отчёт с датой без коммитов
- **THEN** команда завершается успешно, а `research.md` явно сообщает, что подтверждённых
  Git-изменений нет

#### Scenario: Передана некорректная дата

- **WHEN** пользователь передаёт дату не в формате `YYYY-MM-DD`
- **THEN** команда завершается с объяснением корректного формата и не создаёт отчёт

### Requirement: Отчёт связывает факты с OpenSpec без догадок

Отчёт SHALL перечислять только те OpenSpec change, чьи файлы были изменены выбранными Git-коммитами.
Для такого change отчёт SHALL включать его имя и доступное содержимое `proposal.md`; коммит без
изменённого OpenSpec-файла SHALL оставаться в отчёте без вымышленной связи.

#### Scenario: Коммит меняет OpenSpec change

- **WHEN** выбранный коммит меняет файл внутри `openspec/changes/radar-asteroid-markers/`
- **THEN** отчёт содержит `radar-asteroid-markers` и его доступный proposal

#### Scenario: Коммит не меняет OpenSpec

- **WHEN** выбранный коммит меняет только production-код
- **THEN** отчёт включает коммит, но не приписывает ему произвольный change

### Requirement: Skill выдаёт готовый к съёмке материал

Skill ежедневного видеоотчёта SHALL на основе `research.md` подготовить на русском языке: короткий
hook, 2–4 проверяемых тезиса, текст диктора для Shorts и список нужных кадров. Он SHALL помечать
предположения и не представлять незакоммиченные изменения как завершённые.

#### Scenario: Отчёт содержит несколько связанных изменений

- **WHEN** skill получает research-отчёт с несколькими коммитами и OpenSpec change
- **THEN** он группирует их в понятные зрителю тезисы, связывает каждый тезис с кадром и не
  добавляет неподтверждённых фактов

#### Scenario: Отчёт пуст

- **WHEN** skill получает research-отчёт без коммитов
- **THEN** он сообщает, что полноценный отчёт по коммитам составить нельзя, и предлагает только
  кадры текущего состояния как необязательный update

### Requirement: Visible demo по запросу сохраняет два репрезентативных кадра

При заданном `DEMO_CAPTURE_DIR` внутри `artifacts/daily-videos` visible-demo harness SHALL сохранить
`lobby.png` после готовности комнаты и `combat.png` после наблюдения одновременно активного щита и
хотя бы одного снаряда. При отсутствии переменной harness SHALL не создавать PNG-материалы.

#### Scenario: Capture включён

- **WHEN** пользователь запускает `pnpm demo:visible` с допустимым `DEMO_CAPTURE_DIR`
- **THEN** в указанном каталоге появляются `lobby.png` и `combat.png`, представляющие соответственно
  готовый интерфейс и активный бой

#### Scenario: Capture не включён

- **WHEN** пользователь запускает `pnpm demo:visible` без `DEMO_CAPTURE_DIR`
- **THEN** демонстрация работает как прежде и не создаёт capture-каталог

#### Scenario: Capture-каталог небезопасен

- **WHEN** `DEMO_CAPTURE_DIR` указывает за пределы `artifacts/daily-videos`
- **THEN** демонстрация останавливается до запуска браузера с объяснением допустимого расположения

### Requirement: Монтажные исходники и мужская озвучка остаются отдельными

Команда ежедневного отчёта SHALL сохранять `gameplay-raw.mp4` рядом с Markdown-отчётами, если
получен настоящий WebM геймплея. Клип SHALL содержать только видеодорожку игрового процесса: без
аудиодорожки, субтитров, титров и UI-наложений. Озвучка SHALL создаваться только установленным
русским мужским Windows-голосом через SSML с паузами и отмеченными ударениями; женский или нерусский
голос не является допустимым fallback.

#### Scenario: Доступен русский мужской голос

- **WHEN** в Windows установлен включённый голос с культурой `ru-RU` и полом `Male`
- **THEN** команда сохраняет `captures/voice.wav`, `captures/voice.ssml`, чистый `gameplay-raw.mp4`
  и, при наличии геймплея, собирает озвученный `draft.mp4`

#### Scenario: Русский мужской голос не установлен

- **WHEN** команда не находит подходящий SAPI-голос
- **THEN** она сохраняет Markdown и чистый клип, записывает понятное ограничение в `status.md` и не
  создаёт голос, не подменяя его женским или нерусским

### Requirement: UI-кадр админки воспроизводит версию выбранного дня

Если в выбранной ревизии менялись исходники админки, команда SHALL запускать сервер и админку из
отдельного detached worktree этой ревизии и снимать подходящие вкладки Playwright. Кадр SHALL
помечаться как исторический и не может быть снят с текущей рабочей ветки вместо выбранной версии.

#### Scenario: Балансная админка менялась в выбранный день

- **WHEN** коммиты дня изменяют `apps/admin/src/`
- **THEN** отчёт сохраняет PNG вкладок баланса, полученные от локальной админки detached-ревизии, и
  указывает их количество в `status.md`
