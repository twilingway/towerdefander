# Tasks

## 1. Опорный замер до подъёма версии отчётов

Отчёты статистики версионируются без миграций, поэтому всё, что нужно сравнить со «до», снимается и
записывается сюда цифрами, пока `BALANCE_STATS_FILE_VERSION` ещё 1.

- [x] 1.1 Батч на снимке живого пресета: 27 ячеек (3 уровня × 3 сдвига × 3 экипажа), по 30 прогонов,
      сиды 1..30, 810 прогонов всего. Средняя достигнутая волна по уровням: новичок 8.12, ветеран
      8.02, ас 9.17. По сдвигу сложности: −1 → 8.48, 0 → 8.78, +1 → 8.06. По экипажу: 1 → 8.67, 2 →
      8.62, 3 → 8.02. Покупок за прогон 6.5 в среднем. Все 810 прогонов кончились гибелью корабля,
      ни одного таймаута волны.
- [x] 1.2 Распределение достигнутых волн из того же батча: стена на десятой волне — 253 прогона из
      810 кончаются ровно там, ещё 168 на девятой и 152 на пятой; за одиннадцатую уходит 4%,
      максимум за весь батч 20. Отсюда решение не гейтить тир волной; обоснование в `design.md`.
- [x] 1.3 `pnpm benchmark:combat` до правок, 208 динамических сущностей: `pureFixedStep` p50 0.1425,
      p95 0.2804; `schemaSync` p50 0.163, p95 0.1985; `roomFixedStep` p50 0.309, p95 0.4683.
