- [ ] 1.1 Публикация нарисованного кадра при `?diag=1` в `__spaceshipShellProbe`: время кадра, свой
      корпус и срез ствола, корпуса мира с радиусами, снаряды с id, принадлежностью, нарисованной и
      авторитетной позицией, скоростью, тиком снимка. Проверка:
      `pnpm --filter @spaceship-defender/display exec vitest run` и ручной просмотр объекта в e2e.
- [ ] 1.2 Помощник e2e считает разрывы своих и чужих снарядов по формулам спеки. Проверка: unit-тест
      помощника на синтетических кадрах — правильные часы дают 0, сдвиг на `lead` даёт `v × lead`.
- [ ] 1.3 Базовая линия на коде main: сеть (кабина `/arena`) и локальный прогон (`/solo`,
      `/arena/training`) на ходу, результат записан в `design.md`, раздел «Измерения».

## 2. Протокол

- [ ] 2.1 `spawnTick` (`uint32`) в `ProjectileState`, `ProjectileTarget`, схеме снаряда вида display
      и адаптере `roomView`; проекция пишет `spawnedTick`; `PROTOCOL_VERSION` 73. Проверка:
      `pnpm typecheck`, тесты `game-runtime`, `protocol`, серверные тесты комнаты на
      `protocol_mismatch`.

## 3. Часы снаряда

- [ ] 3.1 Чистый модуль `shellClock.ts`: рождение на часах стрелка, скрытие до `spawnTick`, доводка
      со скоростью 0,25, снап при гидратации. Проверка: unit-тесты на каждый сценарий спеки.
- [ ] 3.2 Сеть: `useShipPrediction` отдаёт `{ present, world, own }`, снаряды сняты с `reckon`.
      Проверка: unit-тест хука на подменённых часах и `pendingCount`.
- [ ] 3.3 Локальный прогон: тик позы в драйвере основного потока и в сообщении воркера. Проверка:
      тесты `localRun`.
- [ ] 3.4 Сцена: снаряды рисуются через `shellClock` во всех трёх путях, общий экран без доводки,
      перенос на `lagTicks` для снарядов убран. Проверка: `pnpm typecheck`, `pnpm test`.
