# shared-room-session

## ADDED Requirements

### Requirement: Снимок называет применённый ввод

Комната SHALL публиковать в снимке номер последнего ввода, который она применила, отдельно для
каждого потока команд. Номер SHALL меняться только тогда, когда ввод действительно применён:
отброшенный как устаревший или повторный ввод SHALL NOT поднимать его.

#### Scenario: Ввод применён

- **WHEN** комната применяет ввод пилота с номером N
- **THEN** ближайший снимок называет N подтверждённым для потока пилота

#### Scenario: Повтор отброшен

- **WHEN** приходит ввод с номером не больше уже применённого
- **THEN** подтверждённый номер не меняется

#### Scenario: Прогон начался заново

- **WHEN** начинается новый прогон
- **THEN** подтверждённые номера обнуляются вместе с последовательностями клиента
