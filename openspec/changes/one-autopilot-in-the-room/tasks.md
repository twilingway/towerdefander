## 2. Клиентский срез для бота

- [x] 2.1 Комната собирает боту тот же срез состояния, который уходит на клиент, и передаёт его как
      `world`. Половина уже написана: `buildWorld` в `balance-run.mjs` режет сущности по кадру
      камеры (`insideFrame`), то есть ровно клиентский срез — ему нужен переезд в комнату, а не
      сочинение заново.
- [x] 2.2 Щит ведётся общей политикой; `shieldAutopilot.ts` удаляется вместе с тестом, его дальность
      подъёма и пороги заряда переходят в профиль.
- [x] 2.3 Проверка: сектор в соло ведёт себя как до удаления — держится за врагов в пределах
      дальности, не мигает на паузах между залпами.
