# Атрибуция

Атласы в `atlases/` испечены движком [Arcadia Effects](https://github.com/xaidan777/Arcadia-Effects)
(MIT, © xaidan777). Сам редактор подключён как git submodule в `tools/arcadia-effects` и в сборку не
попадает — он нужен только на машине, где эффекты авторят и запекают.

Два исходника в `effects/` — производные от заводской библиотеки редактора, а не написаны с нуля:

| Наш файл            | Эталон                   | Что изменено                                                                                                |
| ------------------- | ------------------------ | ----------------------------------------------------------------------------------------------------------- |
| `explosion.json`    | `library/Explosion.json` | `cam.comp` 37 → 0 (вид строго сверху), сетка атласа, тёплая вспышка, наши id и английские имена слоёв       |
| `debris-burst.json` | `library/Shockwave.json` | `cam.comp` 37 → 0, кольца волны стали кругами (`aspect` 1.37 → 1, `rot` → 0), сетка атласа, наши id и имена |

`plasma-exhaust.json` и `muzzle-flash.json` собраны по рецептам из
`skills/afx-effect-authoring/SKILL.md` редактора, без копирования данных.

Лицензия эталонов — MIT, её текст лежит в `tools/arcadia-effects/LICENSE`.
