# Звук игры

Две папки, потому что это две разные вещи. `sounds/` — короткие события: выстрел, попадание, взрыв.
Их запускает сцена, они ослабляются по расстоянию, и у каждого есть потолок одновременных копий.
`music/` — темы: длинные, зациклённые, по одной за раз и на своей шине громкости.

Пакет, а не папка внутри дисплея, потому что звуки нужны двоим: дисплей их играет, консоль баланса
даёт их послушать перед тем, как назначить корпусу или врагу. Одна копия на диске, а
`new URL(..., import.meta.url)` в `src/index.ts` — это то, за чем идёт сборщик, поэтому файл
попадает в сборку того приложения, которое его импортировало.

| Файл                         | Что это                    | Длит.  | Откуда           |
| ---------------------------- | -------------------------- | ------ | ---------------- |
| `sounds/cannon.mp3`          | Выстрел пушки              | 0.46 с | `пушка.mp3`      |
| `sounds/machine-gun.mp3`     | Пулемёт, один выстрел      | 0.25 с | `пулемет.mp3`    |
| `sounds/machine-gun-alt.mp3` | Пулемёт, очередь из восьми | 1.10 с | `пулемет2.mp3`   |
| `sounds/explosion.mp3`       | Взрыв корабля              | 2.60 с | `взрыв.mp3`      |
| `sounds/boss-explosion.mp3`  | Взрыв боса                 | 2.32 с | `взрыв боса.mp3` |
| `music/theme-01.*`           | Тема вне боя               | 112 с  | `02music.mp3`    |
| `music/theme-17.*`           | Тема боя                   | 87 с   | `17music.mp3`    |

Исходники пришли по 200–2400 кбит/с, с зашитой обложкой внутри (в полусекунде выстрела было шесть
килобайт звука и сто двадцать картинки) и с хвостом тишины до двух секунд у каждого файла.
Пересобраны так:

```bash
# событие: моно, 96 кбит/с, без метаданных
ffmpeg -i src.mp3 -vn -map_metadata -1 -id3v2_version 0 -ac 1 -b:a 96k -ar 44100 sounds/имя.mp3
# тема: Opus для тех, кто умеет, и mp3 запасным
ffmpeg -i src.mp3 -vn -map_metadata -1 -ac 2 -c:a libopus -b:a 64k music/имя.ogg
ffmpeg -i src.mp3 -vn -map_metadata -1 -id3v2_version 0 -ac 2 -b:a 112k music/имя.mp3
```

Длительности выше — это то, что слышно: хвосты тишины срезаны, на срезе стоит затухание в 60 мс,
чтобы не щёлкало. `пулемет.mp3` был очередью из восьми выстрелов с шагом 80 мс; из него вырезан
последний выстрел вместе с его затуханием, потому что один выстрел на один выстрел синхронен при
любой скорострельности, а очередь пришлось бы растягивать — и вместе с темпом уехала бы высота тона.
Очередь осталась отдельным звуком в `machine-gun-alt`.

Что внутри каждого сэмпла — сколько выстрелов и с каким шагом — записано в `SOUND_SHAPES` в
`src/index.ts`; по этим числам дисплей решает, запускать ли сэмпл заново на очередном выстреле.
Мерялось по огибающей: окна RMS по 5 мс, выстрел засчитывается там, где огибающая переходит четверть
пика, побывав ниже десятой доли.

Opus на слышимом качестве mp3 128 весит вдвое меньше и, в отличие от mp3, зацикливается без щелчка —
у mp3 кодек добавляет тишину в начало и конец файла. Поэтому у тем два формата, а элемент `<audio>`
скачивает только тот, который умеет.

Добавить звук — значит назвать его в `packages/protocol/src/audioCatalogue.ts`, положить файл сюда и
дописать строку в `src/index.ts`. Каталог протокола — то, чем валидируется пресет и что видит
консоль; манифест здесь — то, что играет. Тесты в обоих пакетах не дают им разойтись.
