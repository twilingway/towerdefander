# Castle environment v1

Generated with the built-in image generation tool for `castle-art-pass`.

Use case: `stylized-concept`.

Asset type: 2D game environment background for a 16:9 cooperative tower-defense shared TV screen.

Prompt constraints:

- polished hand-painted fantasy battlefield;
- one large fortified gray-stone castle in the center;
- deep emerald evening forest and warm golden torchlight;
- a road entering from each side and curving toward separate castle gates;
- one mechanical cannon tower beside each gate, pointing outward;
- orthographic three-quarter top-down camera;
- environment only: no enemies, people, text, UI, logos or watermark.

The generated PNG was visually inspected, resized to `1536x864`, and encoded as WebP for the
project. Runtime lane anchors are documented in the active OpenSpec change and intentionally follow
the final illustration.
