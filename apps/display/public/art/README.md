# Ключевой арт стартового экрана

Сюда кладутся две иллюстрации, которые подхватывает стартовый экран дисплея
(`apps/display/src/styles.css`, `.mode-tile--campaign` и `.mode-tile--arena`):

| Файл           | Что на нём                                   | Рекомендуемый размер |
| -------------- | -------------------------------------------- | -------------------- |
| `campaign.jpg` | Кампания I: Завеса — оборона Периметра-7     | 1920×1080, 16:9      |
| `arena.jpg`    | Арена Талос — зона отчуждения, выбор фракции | 1920×1080, 16:9      |

Плитка кадрирует картинку по центру (`background-size: cover`) и кладёт поверх тёмный градиент слева
направо, поэтому важное в композиции лучше держать в правых двух третях кадра — слева ляжет текст.

Файлов может не быть: тогда плитка рисуется своим градиентом и остаётся читаемой. Это сделано
намеренно, чтобы сборка не зависела от того, положил ли кто-то сюда картинки.

Имена фиксированы. Если нужен другой формат (`.webp`, `.png`) — поменяйте путь в `styles.css` рядом
с этими двумя классами.
